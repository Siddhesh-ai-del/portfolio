# Siddhesh Kadlag — Portfolio

Personal portfolio website of Siddhesh Kadlag, an AI & Data Science student passionate about AI, Python, Linux, and problem-solving.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run lint` — run oxlint

## Sections

- Hero / Objective
- Focus areas
- Projects
- Positions & Activities
- Stack & Infrastructure
- Certifications
- Contact / Footer
